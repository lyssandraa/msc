# MSC website

React + Vite + Tailwind. Static, no backend.

## Run

```bash
npm install
npm run dev
```

## Where things are

```
src/data/           all site text
src/pages/          one file per page
src/components/     header, footer, cards
src/App.jsx         routes
src/site.config.js  nav, apply link, contact email
src/index.css       colours and fonts
```
